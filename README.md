One short line about office life, judged head to head. `main.ts` writes a single
office joke to `/output/entry.txt`: the meeting that could have been an email,
answered with a reply-all and a follow-up to discuss the email itself.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
